# HandyFlix Pro — Privacy Policy (Vercel)

Static privacy policy page for APKPure, Play Store, and website links.

## Deploy on Vercel

1. Go to [vercel.com](https://vercel.com) and sign in with GitHub
2. **Add New Project** → import `mr-Colab/HandyFlix-Pro-Releases`
3. Set **Root Directory** to `privacy-policy`
4. Framework Preset: **Other** (static)
5. Deploy

Your URL will look like:

```
https://handyflix-pro-releases.vercel.app
```

Or add a custom domain later, e.g. `https://privacy.freehandyflix.online`

## APKPure field

Use your deployed URL:

```
https://YOUR-PROJECT.vercel.app
```

Both `/` and `/privacy` serve the same page.

## Local preview

Open `index.html` in a browser, or:

```bash
npx serve .
```
